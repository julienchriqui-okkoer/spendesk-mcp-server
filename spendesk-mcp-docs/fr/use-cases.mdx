---
title: Cas d'usage
description: Exemples de prompts pour l'analyse de dépenses, les comptes fournisseurs, la clôture et la gestion des fournisseurs.
---

Copiez-collez ces prompts dans votre assistant IA. Ils sont conçus pour les équipes Finance et utilisent les outils MCP Spendesk.

<AccordionGroup>
  <Accordion title="Analyse de dépenses" defaultOpen>
Utilisez-les pour analyser les dépenses par dimension, fournisseur ou période.

```
Quels sont nos 15 plus gros fournisseurs par montant dépensé de janvier à mars 2026 ?
```

```
Répartis les dépenses par centre de coût pour le T1 2026. Montre le total et la part du total pour chaque.
```

```
Montre l'évolution mensuelle des dépenses sur les 6 derniers mois, par type de payable (facture, note de frais, carte).
```
  </Accordion>
  <Accordion title="Comptes fournisseurs">
Pour l'AP aging, le statut de paiement et la trésorerie.

```
Donne-moi un rapport d'aging AP à ce jour : total en cours, et montants en 0–30, 31–60, 61–90 et 90+ jours de retard.
```

```
Quelles factures sont encore impayées pour janvier–février 2026 ? Liste fournisseur, montant et échéance.
```

```
Quelles sont nos sorties de trésorerie prévues pour les 30 prochains jours à partir des factures impayées, par semaine ?
```
  </Accordion>
  <Accordion title="Clôture mensuelle">
Pour le pipeline compta et la clôture.

```
Quelles factures ne sont pas encore exportées en compta pour février 2026 ? Statut créé ou préparé.
```

```
Pour le dernier mois, donne-moi le détail TVA par taux (net, montant TVA, TTC) pour les payables exportés.
```

```
J'ai besoin d'un résumé type écritures des payables exportés en janvier 2026 : comptes de charge et montants.
```
  </Accordion>
  <Accordion title="Gestion fournisseurs">
Pour les fournisseurs, les PO et les vues par fournisseur.

```
Liste tous les fournisseurs. J'ai besoin des noms et IDs pour filtrer un autre rapport.
```

```
Montre les commandes d'achat ouvertes et leur statut. Filtre par fournisseur si tu as l'ID.
```

```
Combien avons-nous dépensé avec le fournisseur X (nom ou ID) au T1 2026 ? Détaille par mois si possible.
```
  </Accordion>
