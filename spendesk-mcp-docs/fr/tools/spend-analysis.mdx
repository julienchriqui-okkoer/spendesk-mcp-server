---
title: Analyse de dépenses
description: spendesk_analyze_spend — agrégation des dépenses par fournisseur, centre de coût, mois, employé, pays, etc. Paramètres, filtres et exemples.
---

L'outil **spendesk_analyze_spend** agrège les dépenses à partir des payables (factures, notes de frais, cartes) sur une plage de dates et groupe les résultats par la dimension choisie. Utilisez-le pour le top fournisseurs, les dépenses par département, budget vs réalisé ou les analyses par champ analytique.

Pour les paramètres détaillés, les valeurs de `groupBy` et les exemples de prompts, consultez la [version anglaise](/tools/spend-analysis).
