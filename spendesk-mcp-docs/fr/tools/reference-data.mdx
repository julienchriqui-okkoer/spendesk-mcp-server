---
title: Données de référence
description: Fournisseurs, centres de coût, champs analytiques et commandes d'achat. Recherche d'IDs et listes pour l'analyse et les filtres.
---

Les outils de données de référence renvoient des listes et détails utilisables pour filtrer ou interpréter les autres outils (ex. `spendesk_analyze_spend`). Utilisez-les pour obtenir les IDs fournisseurs, lister les centres de coût ou les champs et valeurs analytiques.

Pour les paramètres et exemples, consultez la [version anglaise](/tools/reference-data).
