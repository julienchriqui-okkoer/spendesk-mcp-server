Spendesk MCP connecte vos données Spendesk aux assistants IA comme Claude, Cursor et ChatGPT. Posez des questions en langage naturel et obtenez des réponses à partir de vos dépenses, payables et fournisseurs. Conçu pour les équipes Finance : DAF, contrôle de gestion, contrôleurs et comptables.

## Pour qui

| Rôle | Cas d'usage |
|------|-------------|
| **DAF** | Position de trésorerie, AP en retard, prévision de trésorerie, dépenses par département ou fournisseur. |
| **Contrôleur de gestion** | Dépenses par centre de coût ou champ analytique, tendances mensuelles, budget vs réalisé. |
| **Contrôleur** | Pipeline compta, factures non encore exportées, détail TVA, écritures pour la clôture. |
| **Responsable comptabilité** | Statut de paiement, factures impayées, règlements, données de référence fournisseurs et PO. |

## Fonctionnement

Le serveur MCP Spendesk se situe entre votre assistant IA et l'API publique Spendesk. À chaque question, l'assistant choisit l'outil adapté (analyse de dépenses, AP aging, etc.), le serveur appelle Spendesk avec vos identifiants, et la réponse est transformée en réponse claire.

<Note>
  Le serveur MCP est **en lecture seule**. Il ne crée ni n'approuve de paiements, ne modifie pas les factures ni les données Spendesk. Utilisez-le pour le reporting, l'analyse et la consultation.
</Note>

L'authentification est par token (OAuth 2.0 ou token API). Vous générez un token dans Spendesk (Paramètres → Intégrations → Accès API) et vous le configurez une fois dans votre client IA. Le serveur utilise ce token pour lire les données en votre nom.
