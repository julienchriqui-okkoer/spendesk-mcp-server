Spendesk MCP connects your Spendesk data to AI assistants like Claude, Cursor, and ChatGPT. Ask questions in plain language and get answers from your real spend, payables, and vendor data. Built for Finance teams: CFOs, FP&A, controllers, and accountants.

## Who it's for

| Role | Use case |
|------|----------|
| **CFO** | Cash position, overdue AP, cash flow forecast, high-level spend by department or supplier. |
| **FP&A analyst** | Spend by cost center or analytical field, trends by month, budget vs actual, variance analysis. |
| **Controller** | Bookkeeping pipeline, invoices not yet exported, VAT breakdown, journal entries for month-end. |
| **Accounting manager** | Payment status, unpaid invoices, settlements, supplier and PO reference data. |

## How it works

The Spendesk MCP server sits between your AI assistant and the Spendesk Public API. When you ask a question, the assistant picks the right tool (e.g. spend analysis, AP aging), the server calls Spendesk with your credentials, and the response is turned into a clear answer.

<Note>
  The MCP server is **read-only**. It does not create or approve payments, change invoices, or modify Spendesk data. Use it for reporting, analysis, and lookup.
</Note>

Authentication is token-based (OAuth 2.0 or API token). You generate a token in Spendesk (Settings → Integrations → API access) and configure it once in your AI client. The server uses that token to read data on your behalf.
