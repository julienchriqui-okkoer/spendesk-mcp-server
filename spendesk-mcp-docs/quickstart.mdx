## Step 1 — Get a Spendesk token

1. Log in to [Spendesk](https://app.spendesk.com) (or your Spendesk domain).
2. Go to **Settings** → **Integrations** → **API access management**.
3. Create an API token or get your **Client ID** and **Client Secret** (OAuth 2.0).
4. Copy the token (or both credentials) for the next step.

<Note>
  With Client ID + Client Secret, you will need to generate a Bearer string (see the Dust or Claude guides below).
</Note>

## Step 3 — Try your first prompt

Once the MCP is configured, try for example:

**Top suppliers**

```
What are our top 10 suppliers by spend this quarter?
```

**Overdue invoices**

```
List overdue payables and total amount past due.
```

**Cash position**

```
Give me the cash position: overdue, due today, and due in the next 7 and 30 days.
```

The assistant will call Spendesk tools (e.g. `spendesk_analyze_spend`, `spendesk_get_ap_aging`, `spendesk_get_cash_position`) and return results from your Spendesk data.
