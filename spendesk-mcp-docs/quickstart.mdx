## Step 1: Generate a token in Spendesk

1. Log in to [Spendesk](https://app.spendesk.com) (or your Spendesk domain).
2. Go to **Settings** → **Integrations** → **API access management** (or **Gestion d'accès API**).
3. Create a new API token or use OAuth 2.0 client credentials (Client ID + Client Secret).
4. Copy the token (or Client ID and Client Secret). You will paste it into your AI assistant config in Step 2.

<Note>
  For client credentials (Client ID + Client Secret), use the Bearer format `client_credentials:<base64(client_id:client_secret)>` or send headers `X-Spendesk-Client-Id` and `X-Spendesk-Client-Secret`. See the main docs for your deployment (e.g. Dust, Railway) for the exact auth method.
</Note>

## Step 2: Connect your AI assistant

Configure the MCP server in your assistant. Use the URL and auth below. For **Dust**, see the dedicated [Connect with Dust](/connect-dust) page.

<Tabs>
  <Tab title="Claude">
Add the Spendesk MCP server in Claude (e.g. Claude Desktop or API). Example config:

```json
{
  "mcpServers": {
    "spendesk": {
      "url": "https://spendesk-mcp-server-production.up.railway.app/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_SPENDESK_TOKEN_HERE"
      }
    }
  }
}
```

Replace `YOUR_SPENDESK_TOKEN_HERE` with your Spendesk API token or client-credentials Bearer string.
  </Tab>
  <Tab title="Cursor">
In Cursor, add the MCP server (Settings → MCP). Example:

```json
{
  "mcpServers": {
    "spendesk": {
      "url": "https://spendesk-mcp-server-production.up.railway.app/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_SPENDESK_TOKEN_HERE"
      }
    }
  }
}
```

Use your Spendesk token or client-credentials Bearer in the `Authorization` header.
  </Tab>
  <Tab title="ChatGPT">
In ChatGPT (or your MCP-enabled client), configure the server URL and auth:

```json
{
  "url": "https://spendesk-mcp-server-production.up.railway.app/mcp",
  "headers": {
    "Authorization": "Bearer YOUR_SPENDESK_TOKEN_HERE"
  }
}
```

Set the Bearer token to your Spendesk API token or client-credentials string.
  </Tab>
</Tabs>

## Step 3: Try your first prompts

Use these in your AI assistant to confirm the connection:

**Top suppliers this quarter**

```
What are our top 10 suppliers by spend for this quarter?
```

**Overdue invoices**

```
List our overdue payables and total amount past due.
```

**Spend by cost center**

```
Show spend by cost center for January 2026.
```

The assistant will call the Spendesk MCP tools (e.g. `spendesk_analyze_spend`, `spendesk_get_ap_aging`) and return results from your live Spendesk data.
