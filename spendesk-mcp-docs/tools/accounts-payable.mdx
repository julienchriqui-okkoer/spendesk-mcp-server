Four composite tools cover accounts payable: aging, payment status, cash flow forecast, and a consolidated cash position dashboard.

---

## spendesk_get_ap_aging

Returns AP aging buckets (current, 1–30, 31–60, 61–90, 90+ days overdue), total outstanding, and optional DPO. Data is limited to the last 12 months to avoid timeouts.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `asOfDate` | string | No | Reference date for aging (YYYY-MM-DD). Default: today. |
| `includeUpcoming` | boolean | No | Include not-yet-due unpaid invoices (default false). |

**Example prompts**

```
AP aging report as of today. Show total outstanding and amounts in each bucket: current, 1–30, 31–60, 61–90, 90+ days overdue.
```

```
Which suppliers have the most overdue amounts? Give me the top 10 and their oldest invoice age in days.
```

## spendesk_get_payment_status

Lists payables by payment status: paid, unpaid, or partial. A payable is **paid** when allocations cover the full amount; **partial** when partly allocated; **unpaid** when no allocations.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `from` | string | Yes | Start date (YYYY-MM-DD). |
| `to` | string | Yes | End date (YYYY-MM-DD). |
| `status` | string | No | Filter: `paid`, `unpaid`, or `partial`. Omit for all. |
| `currency` | string | No | Filter by original currency (e.g. EUR, USD). |

**Example prompts**

```
List all unpaid invoices for January and February 2026 with supplier, amount, and due date.
```

```
Show me partially paid invoices in EUR for this quarter.
```

## spendesk_get_cash_flow_forecast

Forecasts upcoming cash outflows from unpaid invoices with due dates. Group by day, week, or supplier.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `days` | number | No | Forecast horizon in days (default 30, max 365). |
| `groupBy` | string | No | `day`, `week`, or `supplier` (default `week`). |
| `asOfDate` | string | No | Reference date (YYYY-MM-DD). Default: today. |

**Example prompts**

```
What are our forecasted cash outflows for the next 30 days from unpaid invoices? Group by week.
```

```
Show upcoming payments by supplier for the next 14 days.
```

---

## spendesk_get_cash_position

Single-call “cash obligations” view: overdue amount, due today, due in next 7 days, due in next 30 days, total outstanding, and top urgent payments (e.g. by days overdue and amount).

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `asOfDate` | string | No | Reference date (YYYY-MM-DD). Default: today. |

**Example prompts**

```
Give me our cash position: how much is overdue, due today, due in the next 7 days, and in the next 30 days? Plus top 20 urgent payments.
```

```
CFO dashboard: total outstanding payables and the most urgent ones to pay (by days overdue).
```
