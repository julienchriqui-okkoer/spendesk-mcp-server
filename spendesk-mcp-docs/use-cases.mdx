---
title: Use cases
description: Example prompts for spend analysis, accounts payable, month-end close, and vendor management.
---

Copy-paste these prompts into your AI assistant. They are designed for Finance teams and use the Spendesk MCP tools.

<AccordionGroup>
  <Accordion title="Spend analysis" defaultOpen>
Use these to analyze spend by dimension, supplier, or time.

```
What are our top 15 suppliers by total spend from January to March 2026?
```

```
Break down spend by cost center for Q1 2026. Show total and share of grand total for each.
```

```
Show monthly spend trend for the last 6 months, grouped by payable type (invoice, expense, card).
```
  </Accordion>
  <Accordion title="Accounts payable">
Use these for AP aging, payment status, and cash flow.

```
Give me an AP aging report as of today: total outstanding, and amounts in 0–30, 31–60, 61–90, and 90+ days overdue.
```

```
Which invoices are still unpaid for the period January–February 2026? List supplier, amount, and due date.
```

```
What are our forecasted cash outflows for the next 30 days from unpaid invoices, grouped by week?
```
  </Accordion>
  <Accordion title="Month-end close">
Use these for bookkeeping pipeline and accounting close.

```
Which invoices are not yet exported to accounting for February 2026? I need status created or prepared.
```

```
For the last month, give me the VAT breakdown by rate (net, VAT amount, gross) for exported payables.
```

```
I need a journal-entry style summary of payables exported in January 2026: expense accounts and amounts.
```
  </Accordion>
  <Accordion title="Vendor management">
Use these for suppliers, POs, and vendor-level views.

```
List all suppliers. I need names and IDs to filter another report.
```

```
Show open purchase orders and their status. Filter by supplier if you have the ID.
```

```
What did we spend with supplier X (use name or ID) in Q1 2026? Break down by month if possible.
```
  </Accordion>
</AccordionGroup>
