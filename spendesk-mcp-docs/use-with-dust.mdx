This guide explains how to configure the Spendesk MCP server in [Dust](https://app.dust.tt), step by step, with the navigation in the interface.

---

## Prerequisites

- A [Dust](https://app.dust.tt) account.
- Your Spendesk credentials: **Client ID** and **Client Secret** (from Spendesk → Settings → Integrations → API access management), or an API key from the MCP server `/ui` portal.

---

## Step 1 — Open the tool configuration

1. Log in to **app.dust.tt**.
2. In the left menu, go to **Spaces** (or **Administration**).
3. Click **Tools**.
4. Click **Add tool** (or edit an existing "Spendesk MCP Server" tool).
5. The right-hand panel opens: **Info** tab by default.

![Tools screen in Dust — add a tool](/img/dust-tools.png)

---

## Step 2 — Enter the MCP server URL

1. In the configuration panel, find the **Server URL** field.
2. Enter exactly:

`https://spendesk-mcp-server-production.up.railway.app/mcp`

3. Do not add a trailing slash.

<Check>
  This is the only URL to use for this MCP; no need for a different URL per environment.
</Check>

![Server URL field filled](/img/dust-server-url.png)

---

## Step 3 — Configure authentication

Dust sends a **Bearer token** (or headers). Choose one option.

### Option A — Bearer with Client ID + Client Secret (recommended)

1. Generate the token on your machine (at the repo root):

```bash
node scripts/generate-dust-bearer.mjs YOUR_CLIENT_ID YOUR_CLIENT_SECRET
```

2. Copy the entire output line (it starts with `client_credentials:`).
3. In Dust, open **Advanced settings** → **Bearer Token (Authorization)**.
4. Paste the string into "Paste the Bearer Token here".
5. Click **Save**.

### Option B — Headers

1. In Dust, **Networking & Headers** → **Add Header**.
2. Add:
   - **Name:** `X-Spendesk-Client-Id` — **Value:** your Client ID
   - **Name:** `X-Spendesk-Client-Secret` — **Value:** your Client Secret
3. **Save**.

![Advanced settings — Bearer or Headers](/img/dust-auth.png)

---

## Step 4 — Sync and test

1. Next to the **Server URL** field, click **Sync** to load the list of MCP tools.
2. You should see many Spendesk tools (spend analysis, AP aging, bookkeeping, etc.).
3. In a Dust **assistant**, ask a question to verify the connection.

<Tip>
  If you get an error, check the URL, the Bearer (or headers), and your Spendesk account permissions (e.g. payables read).
</Tip>

## Example use cases

Here are three typical examples.

### Case 1 — Top 10 suppliers by spend

**Goal:** Get the 10 highest-spend suppliers over a period.

**In Dust**, ask for example:

```
What are our top 10 suppliers by spend for the last quarter?
```

The assistant will use `spendesk_analyze_spend` (groupBy: supplier) and show amounts and shares.

![Dust example — top suppliers](/img/dust-use-top-suppliers.png)

---

### Case 2 — Overdue invoices

**Goal:** See supplier invoices that are past due.

**In Dust**, ask for example:

```
List overdue payables and total amount past due.
```

The assistant will use `spendesk_get_ap_aging` (and possibly `spendesk_get_cash_position`) to show amounts by due date and the most urgent.

![Dust example — overdue](/img/dust-use-overdue.png)

---

### Case 3 — Cash position

**Goal:** A summary view of cash commitments (due today, 7 days, 30 days).

**In Dust**, ask for example:

```
Give me the cash position: what is overdue, due today, and due in the next 7 and 30 days.
```

The assistant will use `spendesk_get_cash_position` to show amounts by category.

![Dust example — cash position](/img/dust-use-cash-position.png)
