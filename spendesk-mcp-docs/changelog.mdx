<Update version="1.0.0" date="March 2026">
- **Initial release** of Spendesk MCP documentation and tool set.
- **Composite tools:** spendesk_analyze_spend, spendesk_get_bookkeeping_pipeline, spendesk_get_payment_status, spendesk_get_ap_aging, spendesk_get_cash_flow_forecast, spendesk_get_cash_position.
- **Core API tools:** settlements, payables (snapshot create/get, single payable, attachments), purchase orders, suppliers, users, cost centers, expense categories, analytical fields/values, API reference.
- **Authentication:** Token-based (API token or OAuth 2.0 client credentials) via Bearer or custom headers; read-only access to Spendesk Public API.
- **Documentation:** Quickstart for Claude, Cursor, and ChatGPT; use cases for spend analysis, AP, month-end close, and vendor management; tool reference with parameters and example prompts; troubleshooting for 401, 403, empty results, 409, date range, and MCP connection.
</Update>
