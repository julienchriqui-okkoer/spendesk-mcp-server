This guide explains how to configure the Spendesk MCP server with **Claude** (Claude Desktop or another MCP client), step by step, with the navigation in the tool.

---

## Prerequisites

- [Claude Desktop](https://claude.ai/download) (or an MCP-capable client).
- Your Spendesk credentials: API token or **Client ID** + **Client Secret**, or an API key from the MCP `/ui` portal.

---

## Step 1 — Open Claude MCP configuration

1. Open **Claude Desktop** (or your Claude client).
2. Go to **Settings** (gear icon or menu).
3. Find the **MCP** or **Model Context Protocol** / **Developers** section.
4. You will see the list of MCP servers and a way to **add** or **edit** a server (config file or form depending on version).

![Settings / MCP screen in Claude](/img/claude-settings.png)

---

## Step 2 — Add the MCP server URL

1. Create or edit an MCP server entry (e.g. name "spendesk").
2. Set the server **URL** to:

`https://spendesk-mcp-server-production.up.railway.app/mcp`

3. Do not add a trailing slash.

<Check>
  This is the only URL to use for this MCP.
</Check>

![MCP config — URL field](/img/claude-config-url.png)

---

## Step 3 — Configure authentication

Claude sends HTTP headers to the MCP server. You must send a **Bearer token**.

1. In the MCP config, add a **headers** entry (or equivalent) with:
   - **Authorization:** `Bearer YOUR_TOKEN`
2. Replace `YOUR_TOKEN` with:
   - your **Spendesk API token**, or
   - the **client_credentials** string from:  
     `node scripts/generate-dust-bearer.mjs YOUR_CLIENT_ID YOUR_CLIENT_SECRET`  
     (same format as for Dust).
3. Example configuration (format expected by Claude Desktop):

```json
{
  "mcpServers": {
    "spendesk": {
      "url": "https://spendesk-mcp-server-production.up.railway.app/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN_HERE"
      }
    }
  }
}
```

4. Save the file or configuration, then **restart Claude** if needed.

![Example config with headers](/img/claude-auth.png)

---

## Step 4 — Verify and test

1. Restart Claude Desktop (or reload the MCP config) to apply changes.
2. Open a new conversation.
3. Ask a question that requires Spendesk data to confirm MCP tools are called.

<Tip>
  If you get an error, check the URL, the `Authorization: Bearer ...` header, and your Spendesk token permissions.
</Tip>

---

## Example use cases

Three examples to use in Claude.

### Case 1 — Top 10 suppliers by spend

**Goal:** Get the 10 highest-spend suppliers over a period.

**In Claude**, ask for example:

```
What are our top 10 suppliers by spend for the last quarter?
```

Claude will use `spendesk_analyze_spend` (groupBy: supplier) and show amounts and shares.

![Claude example — top suppliers](/img/claude-use-top-suppliers.png)

---

### Case 2 — Overdue invoices

**Goal:** See supplier invoices that are past due.

**In Claude**, ask for example:

```
List overdue payables and total amount past due.
```

Claude will use `spendesk_get_ap_aging` (and possibly `spendesk_get_cash_position`) to show amounts and the most urgent.

![Claude example — overdue](/img/claude-use-overdue.png)

---

### Case 3 — Cash position

**Goal:** Summary view of cash commitments (due today, 7 days, 30 days).

**In Claude**, ask for example:

```
Give me the cash position: what is overdue, due today, and due in the next 7 and 30 days.
```

Claude will use `spendesk_get_cash_position` to show amounts by category.

![Claude example — cash position](/img/claude-use-cash-position.png)
